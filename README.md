# NexusNet Sub v3.4
Subscription themes for **3x-ui (Sanaei)** and **PasarGuard**. No CDN needed.

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/SiNaKeEn/NexusNet-Sub/Themes/install.sh)
```
```bash
nxt-sub
```

- Blue theme by default; the whole page turns **red** when the service is disabled, quota is used up or it has expired.
- PasarGuard: open the page with `#debug` at the end of the URL to see the raw values the panel sent.
- Sources in `src/`; `python3 build.py` rebuilds both themes into `out/`.
